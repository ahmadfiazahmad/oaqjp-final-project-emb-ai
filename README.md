# Final Project

## Project Overview
This project is an **Emotion Detection Application** built using Python, the Watson NLP Library, and Flask for web deployment. It allows users to input text and analyze emotions such as anger, disgust, fear, joy, and sadness, identifying the dominant emotion and handling errors gracefully.

---

## Project Structure
- `server.py`[cite: 1] - Flask web server and routing for the application interface.
- `EmotionDetection/`[cite: 1] - Python package folder containing:
  - `__init__.py`[cite: 1] - Module initialization script.
  - `emotion_detection.py`[cite: 1] - Core logic for emotion analysis and Watson NLP integration.
- `test_emotion_detection.py`[cite: 1] - Unit test script for validating the emotion detector functions.
- `static/`[cite: 1] - Frontend assets including JavaScript (`mywebscript.js`)[cite: 1].
- `templates/`[cite: 1] - HTML template files (`index.html`)[cite: 1] for the user interface.
